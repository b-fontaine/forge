# Design — `t8-example-tree-pins`

## The three files, produced the way the example was produced

`examples/README.md` says each tree "was generated by running the actual archetype
scaffolder once … then committed verbatim". The fix keeps that true: substitute
`<project-name>` → `forge-rag-example` in the three template files and write the result.
Measured before writing anything: rendering all eleven `web-public` templates produces a
tree that differs from the committed example in exactly `package.json`, `README.md` and
`vite.config.ts`, with no missing or extra file — so this is the subtree re-render, not a
patch that happens to look like one.

## The discovery root, and the floor that makes it honest

Both guards become a two-root sweep:

```
{ find "$FORGE_ROOT/.forge/templates" -name 'package.json.tmpl' -type f
  find "$FORGE_ROOT/examples"        -name 'package.json'      -type f -not -path '*/node_modules/*'
} | sort
```

Two traps this must avoid, both of which a prototype hit:

1. **The README sibling.** T-014 derives `README.md.tmpl` from the manifest path. For an
   example the sibling is `README.md`. Derive the suffix from the discovered file instead
   of hardcoding it, or T-014's README half silently skips every example — a vacuity
   trap that passes.
2. **The floor.** `checked == 0` cannot detect "the examples root matched nothing",
   because the template surfaces keep the count positive. Each test needs a **scoped**
   floor: at least one discovered surface under `examples/`. That is the assertion that
   fails if `examples/` is renamed, moved into the tarball differently, or excluded by a
   future refactor.

`node_modules` is excluded at the find, so a developer who has installed dependencies in
an example does not turn the harness red (and the exclusion is cheap to prove: create
one, run the test).

## What stays out, and why

`connect-client.ts` in the same example imports a path buf does not generate (Q-006). It
is **byte-identical to the template**, so it is template drift, not example drift, and it
belongs to the codegen brick that fixes both at once. Fixing it here would leave the
template broken and make the example diverge — the inverse of this brick's contract.

2. GREEN: write the three rendered files → `b8-9` 14/14.
